# KubeLab — изучаем Kubernetes на Windows

**Отдельное приложение для Windows, в котором можно изучать Docker, Minikube и Kubernetes через практику во встроенной консоли.**

Урок, команды и объяснения находятся рядом. Вводишь команду, читаешь результат и разбираешься, что произошло. Если встречается знакомая ошибка, приложение подсвечивает её и предлагает следующий шаг.

> **Статус:** ранний локальный прототип. В этом репозитории пока опубликовано описание проекта. Исходники и первая Windows-сборка будут опубликованы следующими шагами. Готового публичного релиза сейчас нет.

## Для кого

Для тех, кто хочет освоить Kubernetes с нуля на своём Windows-компьютере и понять на практике:

- чем образ отличается от контейнера;
- зачем нужны Pod, Deployment и Service;
- как запустить локальный кластер через Minikube;
- как масштабировать приложение, менять настройки и откатывать обновления;
- как читать логи и находить причины ошибок.

Не нужен облачный кластер. Для реальных упражнений используется локальный Minikube с Docker-драйвером.

## Как проходит обучение

1. Открываешь урок: короткое объяснение, цель и команды.
2. Вводишь команду самостоятельно или нажимаешь на пример, чтобы вставить его в консоль.
3. Запускаешь команду и видишь её вывод.
4. Если возникла ошибка — читаешь объяснение и предлагаемую команду исправления.
5. Сверяешь результат с заданием, отвечаешь на вопрос и отмечаешь урок как пройденный.

Например, при вводе `minicube` приложение подсказывает правильное название — `minikube`. Если Pod показывает `ErrImageNeverPull`, подсказка предлагает проверить тег и загрузить образ в Minikube:

```text
minikube image load kubelab:1.0 -p kubelab
```

Подсказки работают по локальным правилам и известным сообщениям ошибок. Они помогают с диагностикой, но не гарантируют определение любой неисправности.

## Два режима консоли

| Режим | Как работает | Что нужно |
| --- | --- | --- |
| **Тренажёр** | Моделирует команды и состояние учебного кластера. Не запускает процессы и не меняет компьютер. | Само приложение. Docker и кластер не нужны. |
| **Реальные команды** | Запускает установленные `docker`, `minikube` и `kubectl`. Показывает настоящий вывод. Команды действительно меняют контейнеры и ресурсы кластера. | Docker Desktop, Minikube и kubectl. |

По умолчанию включён тренажёр. Его модель упрощена и поддерживает команды курса, а не весь синтаксис Kubernetes.

Встроенная консоль предназначена для работы с этими тремя CLI. Это не полноценный PowerShell: конвейеры, перенаправления, интерактивный `-it` и внешние редакторы внутри неё не поддерживаются.

## Что есть в локальном прототипе

- Русский интерфейс и восемь практических уроков.
- Поле ввода команд с подсветкой некоторых ошибок синтаксиса.
- Вывод команд по мере выполнения, выделение ошибок и код завершения процесса.
- Объяснения типовых проблем: отсутствующий образ, недоступный Docker, отсутствующий профиль Minikube, занятый порт, `CrashLoopBackOff`.
- История команд по **↑ / ↓** и дополнение команд курса по **Tab**.
- Кнопка **«Стоп»** для длительных команд, например `port-forward`.
- Выбор рабочей папки проекта.
- Шпаргалка с поиском, схема учебного стенда и локальный прогресс обучения.

Прогресс отмечается самим учеником после практики и правильного ответа на вопрос. Автоматической проверки реального кластера пока нет.

## Программа практикума

| № | Тема | Что попробуем |
| --- | --- | --- |
| 1 | Docker | Собрать образ, запустить контейнер, посмотреть логи. |
| 2 | Minikube | Создать локальный кластер и проверить готовность Node. |
| 3 | Pod и Deployment | Загрузить образ в Minikube и развернуть две реплики приложения. |
| 4 | Service и сеть | Найти приложение через Service и открыть его на Windows через `port-forward`. |
| 5 | Масштабирование | Изменить число реплик и посмотреть, как Kubernetes восстанавливает Pod. |
| 6 | ConfigMap | Изменить настройку без пересборки образа и понять, когда она попадёт в контейнер. |
| 7 | Обновление и откат | Изменить шаблон Deployment, проверить rollout и вернуть предыдущую версию. |
| 8 | Диагностика | Намеренно указать отсутствующий образ, прочитать Events и восстановить приложение. |

## Приложение само становится учебным стендом

В локальном проекте подготовлено небольшое веб-приложение, которое можно собрать в Docker-образ и развернуть в Minikube. На нём изучаются реальные объекты Kubernetes.

```text
Windows
└── Docker Desktop · Linux containers
    └── Minikube · профиль kubelab
        └── Namespace kubelab
            ├── Deployment → ReplicaSet → Pod приложения
            ├── Service → доступ к готовым Pod
            └── ConfigMap → настройки контейнеров
```

Его API `/api/runtime` показывает имя Pod, namespace, версию, сообщение из настроек, время работы и счётчик запросов процесса. Так можно увидеть последствия перезапуска и обновления приложения.

Для доступа с Windows используется `kubectl port-forward`. Такой туннель связан с одним выбранным Pod и сам по себе не демонстрирует балансировку между репликами.

## Что понадобится на Windows

**Для тренажёра:** готовая сборка приложения — после публикации первого релиза.

**Для работы с настоящим кластером:**

1. Docker Desktop с WSL 2 backend и режимом **Linux containers**.
2. Minikube.
3. kubectl, доступный через `PATH`.
4. Интернет для первого скачивания компонентов и образов.
5. Ресурсы для Windows, Docker и кластера: учебный профиль настроен на **2 CPU и 3072 МБ RAM**. Это ресурсы профиля, а не общие требования ко всему компьютеру.

Включать встроенный Kubernetes в Docker Desktop для этого курса не требуется. Minikube создаёт собственный учебный кластер.

Инструкции по установке инструментов:

- [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/)
- [Minikube: начало работы](https://minikube.sigs.k8s.io/docs/start/)
- [Docker-драйвер Minikube](https://minikube.sigs.k8s.io/docs/drivers/docker/)
- [kubectl для Windows](https://kubernetes.io/docs/tasks/tools/install-kubectl-windows/)

## Техническая основа

- **Electron** — отдельное окно Windows-приложения.
