# Сертификат GigaChat

Источник: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

Ссылка опубликована в официальной инструкции: https://developers.sber.ru/docs/ru/gigachat/certificates

Скачан через HTTPS с проверкой цепочки Node.js. Это публичный корневой сертификат, не секретный ключ.

SHA-256 сертификата (DER): D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31

Срок действия: до 27 февраля 2032. Отпечаток проверяется при загрузке. Используется только в HTTPS-запросах к `ngw.devices.sberbank.ru:9443/api/v2/oauth` и `api.giga.chat/v1/chat/completions`. Проверка TLS и имени узла включена, перенаправления не выполняются. Системное хранилище Windows и переменные TLS не меняются.
