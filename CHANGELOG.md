# Изменения

## 0.1.0-alpha.3

- Переписаны семь уроков Kubernetes. Добавлены объяснения задач и команд, разбор параметров, примеры вывода, задания и ответы с объяснениями.
- Текст урока расположен слева, консоль — рядом. Команду можно вставить, прочитать объяснение и выполнить отдельно.
- Убраны рекламные фразы, пример docker version и быстрые кнопки Docker. По умолчанию показана команда Minikube.
- Мастер компонентов показывает итоговый экран с одной кнопкой «Закрыть», если всё установлено. Отдельно объясняется случай, когда Docker установлен, но не запущен.
- Проверка компонентов перенесена с главного экрана в раздел «Помощь».
- Сохраняются существующий прогресс и механизм обновлений alpha.2.

Проверки: 11 автоматических проверок и браузерная проверка текста урока, вставки и выполнения команд, объяснения ответа, сохранения прогресса и страницы помощи. Полный сценарий установки на чистую Windows и перезагрузки по-прежнему не проверен.

## 0.1.0-alpha.2

Проверка релизов GitHub, скачивание обновлений по кнопке и установка с перезапуском. Дифференциальная загрузка использует старые блоки установщика при наличии кэша.

## 0.1.0-alpha.1

Первый Windows-установщик, мастер компонентов, учебная и реальная консоли.
