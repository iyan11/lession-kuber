# Программа KubeLab

Практический курс Kubernetes на Windows с Minikube. Предполагается знакомство с Docker. Команды выполняются только в учебном контексте kubelab; объекты приложения находятся в пространстве имён kubelab.

| Урок | Практический результат |
| --- | --- |
| 1. Кластер и kubectl | Запуск профиля, проверка компонентов и готовности узла |
| 2. Образ и манифест | Сборка предоставленного приложения, подробное чтение YAML и создание объектов |
| 3. Service и доступ | Проверка селекторов, получателей и временного перенаправления порта |
| 4. Реплики | Изменение числа копий и наблюдение за заменой удалённых Pod |
| 5. ConfigMap | Изменение настройки и проверка её получения новым процессом |
| 6. Обновление и откат | Изменение шаблона, наблюдение за заменой и проверка отката |
| 7. Диагностика | Различия между статусом, событиями и журналами |
| 8. Проверки и ресурсы | Неготовность при работающем процессе, исправление проверки, единицы ресурсов |
| 9. Secret | Передача выдуманного значения без вывода содержимого в журнал |
| 10. Хранилище | Сохранение файла после замены Pod и последствия удаления заявки |
| 11. Права доступа | Узкая роль, привязка и проверки разрешённых и запрещённых действий |

## Как писать уроки

Сначала описывайте задачу и причины выбора решения. Затем вводите термины, показывайте полный используемый файл, объясняйте поля и связи. Для каждой команды нужны цель, параметры, ожидаемый результат и действия при другом результате. Сокращения из интерфейса объясняйте при первом появлении. Фрагмент файла явно помечайте как фрагмент, чтобы его не приняли за готовый манифест.

Указывайте предварительное состояние, последствия удаления и способ завершения опыта. Отдельно объясняйте различия между файлом, сохранённым объектом и работающим процессом. Не выдавайте изменение строки версии за обновление кода и временное перенаправление порта за проверку балансировки.

Основные семь уроков сохраняют прежний порядок и индексы, чтобы существующий прогресс оставался привязан к тем же темам. Новые занятия добавляются в конец. Тренажёр моделирует их команды, но не читает пользовательский YAML, не создаёт реальные тома и не проверяет настоящий доступ. Проверки тренажёра не заменяют прохождения в Minikube.
