# Что ещё нужно сделать

Текущее состояние исходников: alpha.6. Уже есть семь уроков, тренажёр, запуск реальных команд, мастер подготовки Windows, обновления и вопросы к OpenRouter, GigaChat или локальной Ollama. Опубликованные установщики смотрите в [Releases](https://github.com/iyan11/lession-kuber/releases); код в `main` может быть новее последнего установщика.

## Проверки на настоящей Windows

- Установка на чистую Windows: отсутствующие компоненты, запрос прав, необходимая перезагрузка, повторная проверка и итог «всё установлено».
- Обновление установленной версии: полный и дифференциальный варианты загрузки, видимость прогресса и установщика, перезапуск, сохранение прогресса уроков и ключей.
- Полное прохождение семи уроков в реальном Minikube: от создания профиля до восстановления после ошибки образа.
- Работа вопросов к каждому провайдеру с личным ключом или локальной моделью: успех, лимит, недоступность, отмена и нехватка памяти.

Для отчёта указывайте версии Windows, приложения, Docker и Minikube, шаги и результат. Секреты и kubeconfig не прикладывайте. Эти проверки пока нельзя считать завершёнными только по автоматическим тестам.

## Небольшие задачи для первого участия

- Найти шаг урока, где не хватает объяснения, и дописать его вместе с примером результата.
- Проверить порядок клавиатурного фокуса в консоли, окне вопросов и окне обновления; исправить конкретную неудобную последовательность.
- Проверить читаемость длинных команд и сообщений при небольшом окне приложения.
- Добавить понятную подсказку для ещё одной воспроизводимой ошибки Kubernetes с примером входного сообщения.

## Дальнейшее развитие

- Дополнительные уроки: ресурсы контейнеров, probes, Secrets без публикации значений, диагностика сетевых соединений.
- Более точные сценарии тренажёра и проверки результатов урока на настоящем кластере с явным выбором учебного контекста.
- Подписанные сборки Windows и воспроизводимый процесс выпуска.

Перед большой задачей создайте [issue](https://github.com/iyan11/lession-kuber/issues/new/choose). Обсудим объём, чтобы несколько участников не делали одну и ту же работу.
